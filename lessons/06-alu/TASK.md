# Task — Lesson 06

1. Keep the `x`, `y`, `z`, `p`, and `q` split from lesson 05. Use one helper per operation so the register form and the immediate form share a flag rule. `H` is the half-carry out of bit 3 on an add, or the borrow from bit 4 on a subtract. `C` is that test on the whole byte. `ADC` and `SBC` include the old `C` as 0 or 1 in the result and in `H`.
2. Block 2 (`x === 2`): `ALU A, r8`. `y` selects `ADD`, `ADC`, `SUB`, `SBC`, `AND`, `XOR`, `OR`, or `CP`. `z` is the `r8` operand, and index 6 reads `(HL)`. Return 4 T-cycles, or 8 when `z === 6`. `CP` writes flags and leaves `A` as it was.
3. Block 3 (`x === 3 && z === 6`): the same eight operations on an `imm8` from `fetch8`. Return 8 T-cycles. `ADD A, imm8` is `0xC6`. `AND A, imm8` is `0xE6`.
4. Flags for those eight: `ADD`/`ADC` clear `N` and set `Z`, `H`, and `C` from the sum. `SUB`/`SBC`/`CP` set `N`, and `H` and `C` are borrows. `AND` sets `H` and clears `N` and `C`. `XOR` and `OR` clear `N`, `H`, and `C`. `Z` is set when the result is 0.
5. Block 0: `INC r8` is `z === 4` and `DEC r8` is `z === 5`, with the register in `y`. Return 4 T-cycles, or 12 when `y === 6` (`(HL)`). Both set `Z` from the result and leave `C` alone. `INC` clears `N` and sets `H` when the low nibble was `0xF`. `DEC` sets `N` and sets `H` when the low nibble was `0`.
6. Block 0, 16-bit: `ADD HL, r16` is `q === 1 && z === 1` (8 T-cycles). `Z` stays, `N` clears, `H` is the carry out of bit 11, and `C` is the carry out of bit 15. `INC r16` is `q === 0 && z === 3` and `DEC r16` is `q === 1 && z === 3` (8 T-cycles). Neither writes `F`. Pair 3 is `SP`. `q === 0 && z === 1` stays `LD r16, imm16` from lesson 05.
7. `ADD SP, imm8` (`0xE8`, 16 T-cycles) writes `SP`. `LD HL, SP+imm8` (`0xF8`, 12 T-cycles) writes `HL` and leaves `SP`. The immediate is signed for the 16-bit result (`0x80`–`0xFF` means `imm8 - 256`) and unsigned for the flags: `Z` and `N` clear, `H` and `C` come from the low nibble and low byte of `SP + imm8`.
8. Block 0, `z === 7`, 4 T-cycles: `RLCA` `0x07`, `RRCA` `0x0F`, `RLA` `0x17`, `RRA` `0x1F`. Clear `Z`, `N`, and `H`. `C` is the bit that rotated out. `RLCA`/`RRCA` rotate `A` through itself. `RLA`/`RRA` shift the old `C` into the vacant bit. `Z` is clear even when the result is 0. `CPL` `0x2F` inverts `A` and sets `N` and `H`, leaving `Z` and `C`. `SCF` `0x37` clears `N` and `H` and sets `C`. `CCF` `0x3F` clears `N` and `H` and flips `C`.
9. `DAA` (`0x27`, 4 T-cycles). When `N` is clear, add `0x06` if `H` is set or the low nibble is above 9, and add `0x60` if `C` is set or `A` is above `0x99`, which also sets `C`. When `N` is set, subtract those adjustments and keep the old `C`. Test `A > 0x99` before adding `0x06`. Then clear `H`, set `Z` from the adjusted `A`, and leave `N`.
10. Run `npm run test:lesson -- 06`. The test checks three cases: `LD A, 0xFF` then `ADD A, 1` leaves `A = 0` with `Z` and `C` set; `LD A, 0xF0` then `AND 0x0F` leaves `A = 0` with `Z` set; `LD C, 0x0F` then `INC C`, with carry already set, leaves `C = 0x10` with `H` set and carry still set. The other families above are part of this lesson too.
