# Lesson 19: MBC2 & MBC3

MBC2 has 512×4-bit built-in RAM. MBC3 adds ROM/RAM banking plus RTC registers (`0x08–0x0C`) — keep RTC simple for this course.

Pan Docs: https://gbdev.io/pandocs/MBC2.html · https://gbdev.io/pandocs/MBC3.html
