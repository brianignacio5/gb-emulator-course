# Task — Lesson 08

1. `0xCB` is block 3, `z === 3`, `y === 1`. `fetch8` reads the second byte and splits it into `x` (bits 7–6), `y` (bits 5–3), and `z` (bits 2–0). `z` is the `r8` operand from lesson 05, and index 6 is `(HL)`. Use `getR` and `setR`. `JP imm16` stays `y === 0` of that column. Leave `DI` (`0xF3`) and `EI` (`0xFB`) unimplemented.
2. A register operand returns 8 T-cycles. `BIT (HL)` (`x === 1 && z === 6`) returns 12, because it only reads. Every other `(HL)` form returns 16, because it reads the byte and writes it back. Both fetches advance `PC`, so the instruction is two bytes.
3. `x === 0`: `y` selects `RLC`, `RRC`, `RL`, `RR`, `SLA`, `SRA`, `SWAP`, or `SRL`, and the result is written back. The rotates and shifts clear `N` and `H`, set `C` from the bit that shifted out, and set `Z` when the result is 0. `RL` and `RR` read the old `C` before writing flags. `RLC` moves bit 7 into bit 0. `RRC` moves bit 0 into bit 7. `RL` shifts the old `C` into bit 0. `RR` shifts the old `C` into bit 7. `SLA` shifts in a 0 at bit 0. `SRA` keeps bit 7. `SRL` shifts in a 0 at bit 7. `SWAP` exchanges the nibbles, sets `Z` from the result, and clears `N`, `H`, and `C`. These CB rotates set `Z` from the result. Lesson 06's `RLCA`, `RRCA`, `RLA`, and `RRA` clear `Z` and only touch `A`.
4. `x === 1`: `BIT y, r8`. Set `Z` when bit `y` of the operand is 0, clear `N`, set `H`, and leave `C`. Do not write the operand.
5. `x === 2`: `RES y, r8` stores `v & ~(1 << y)`. `x === 3`: `SET y, r8` stores `v | (1 << y)`. Leave `F` alone.
6. Run `npm run test:lesson -- 08`. The test covers `RLC B` (`0xCB 0x00`) turning `B = 0x80` into `0x01` with `Z` clear and `C` set, then `BIT 7, B` (`0xCB 0x78`) setting `Z`, clearing `N`, setting `H`, and leaving `C` and `B`. It covers `SWAP A` (`0xCB 0x37`) turning `A = 0x1F` into `0xF1` with every flag clear, then `SET 0, A` (`0xCB 0xC7`) leaving `A = 0xF1` and `RES 0, A` (`0xCB 0x87`) leaving `A = 0xF0`, both without writing `F`. Every second byte `0x00`–`0xFF` runs on `B` through `A` and on `(HL)`. Rotates, shifts, `SWAP`, and `BIT` use operand `0xB1` with `C` set (`BIT` also starts with `C` clear on half of the opcodes and does not write the operand). `RES` runs on `0xFF` and `SET` on `0x00`, and both leave a preset `F` alone. A register operand returns 8 T-cycles, `BIT (HL)` returns 12, every other `(HL)` form returns 16, and `PC` advances by 2. Separate cases cover a zero result (`RLC` of `0x00` sets `Z`), `RL` and `RR` reading the old `C`, `SLA`, `SRA`, `SRL`, and `SWAP` of a zero or sign result, and `SRA (HL)` of `0x80` writing `0xC0` in 16 T-cycles.
